# Windows-Utility-Apps


Windows Utility Apps is a collection of simple Windows desktop applications developed using C# Windows Forms.

The goal of this repository is to build practical tools that help users organize files, manage tasks, clean folders, track reminders, analyze storage, and access useful computer features more easily.

These apps are created as personal utility projects and portfolio work by Mohammed Ahmed.

## Purpose

This repository focuses on small, useful, and easy-to-use desktop tools.

Each app is designed to solve a simple daily problem, such as:

- Organizing files and folders
- Managing notes and tasks
- Creating reminders
- Cleaning downloads or desktop folders
- Checking disk space usage
- Opening important tools faster
- Improving daily computer productivity

The main idea is to create applications that are simple enough for normal users, but still useful enough to show real programming and problem-solving skills.

## What These Apps Focus On

- Clean and simple Windows interfaces
- Easy buttons and clear actions
- Local data storage
- Search and filtering features
- Safe delete and move actions
- Confirmation before dangerous actions
- No external database required
- Practical tools for students, users, and IT support tasks

## Built With

- C#
- Windows Forms
- Local AppData file-based storage
- Windows desktop environment

## Data Storage

Most apps save their data locally on the user's computer.

The apps do not require:

- Access
- SQLite
- SQL Server
- External online database

Some apps save only settings, while others save user-created data such as notes, tasks, reminders, or shortcuts.

## Security Notice

These apps are not digitally signed yet, so Windows SmartScreen may show a warning.

To run the app:

1. Click **More info**
2. Click **Run anyway**

Only run the apps if they were downloaded from the official GitHub repository.

For more details, see [SECURITY.md](SECURITY.md).
