File Organizer


## Security Notice

These apps are not digitally signed yet, so Windows SmartScreen may show a warning.

Please read [SECURITY.md](../SECURITY.md) for more details.



File Organizer is a desktop app that helps you organize files quickly by type.
Instead of sorting files manually, you can choose a folder and let the app organize files into clear groups such as Images, Videos, Documents, Archives, and Others.
It is made to save time and keep folders clean and easy to browse.

Best for: arranging mixed files into organized folders.
