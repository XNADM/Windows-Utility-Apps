Task Manager


## Security Notice

These apps are not digitally signed yet, so Windows SmartScreen may show a warning.

Please read [SECURITY.md](../SECURITY.md) for more details.



Task Manager is a desktop app for managing daily and weekly tasks.
You can add tasks, update them, check their status, view reports, and keep your work organized.
It helps users follow their tasks clearly instead of keeping everything scattered.

Best for: tracking personal tasks and weekly work.
