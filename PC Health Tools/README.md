PC Health Tools


## Security Notice

These apps are not digitally signed yet, so Windows SmartScreen may show a warning.

Please read [SECURITY.md](../SECURITY.md) for more details.



PC Health Tools gives you quick access to useful Windows tools from one clean screen.
You can open Task Manager, Device Manager, Disk Cleanup, Windows Security, Windows Update, Control Panel, Downloads folder, Temp folder, and more.
The app also shows basic disk space information, so you can quickly check your main drive status.

Best for: opening important Windows tools faster.
