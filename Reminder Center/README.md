Reminder Center


## Security Notice

These apps are not digitally signed yet, so Windows SmartScreen may show a warning.

Please read [SECURITY.md](../SECURITY.md) for more details.



Reminder Center helps you create reminders with date, time, priority, and notes.
When the reminder time comes, the app shows an alert. You can mark the reminder as completed or snooze it for minutes, hours, or days.
If you close the app using X, it hides in the tray and reminders keep working in the background.

Best for: personal reminders and task alerts.
