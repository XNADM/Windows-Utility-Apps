\# Security Notice



These Windows desktop apps are developed by Mohammed Ahmed using C# Windows Forms.



\## Windows SmartScreen



The apps are not digitally signed yet, so Windows may show:



"Windows protected your PC"



This can happen because the app is new and not widely downloaded yet.



\## How to Run



If SmartScreen appears:



1\. Click \*\*More info\*\*

2\. Click \*\*Run anyway\*\*



Only run the app if you downloaded it from the official GitHub repository.



\## Safety



\- Source code is available for review.

\- Apps work locally on your computer.

\- Apps do not upload your files or personal data.

\- Apps that delete or move files ask for confirmation first.

\- System folders are protected where applicable.
