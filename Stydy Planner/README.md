Study Planner


## Security Notice

These apps are not digitally signed yet, so Windows SmartScreen may show a warning.

Please read [SECURITY.md](../SECURITY.md) for more details.



Study Planner helps students organize study tasks and track what needs to be done.
You can add subjects, study tasks, dates, notes, and status.
It is simple and clear, so students can plan their studying without using complicated tools.

Best for: students who want a simple study schedule.
